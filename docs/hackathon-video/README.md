# Beckett Hackathon Video Kit

This folder contains the production materials for the 3-minute Beckett for Slack hackathon video.

## Files

- `teleprompter-script.md`: the exact voiceover script with timing and on-screen actions.
- `shot-list-and-edit-guide.md`: what should be on screen at each moment, including when to use live video, a word slide, or a static pause.
- `title-card.svg`: 16:9 title card for the `0:22` product intro.
- `closing-card.svg`: 16:9 closing card for the final line.

## Recommended Raw Recordings

Record these in 16:9, ideally 1920x1080:

- `beckett-respond-demo.mov`: Slack thread with Jordan's vague message, message shortcut, and Beckett response.
- `beckett-reply-draft-demo.mov`: quick `/beckett respond` example showing reply options for the same vague message.
- `beckett-prep-demo.mov`: `/beckett prep I need to talk to my manager about workload in my 1:1` and the guided prep output.
- `beckett-voiceover.m4a`: clean voiceover, if you do not narrate live while screen recording.

## Final Video Shape

- Target length: `2:45` to `2:55`
- Hard maximum: under `3:00`
- Format: mostly live Slack screen recording
- Slides: title card around `0:22`, closing card at the end
- Do not show GitHub, Supabase, Vercel, settings, signup, architecture diagrams, or the broader web app.

## Export Checklist

- Text in Slack is readable.
- First 30 seconds show the problem and Beckett in Slack.
- First 60 seconds include a working product demo.
- Audio has no long pauses, background noise, or typing dead air.
- Final export is under 3 minutes.
- Uploaded video plays in an incognito/private browser window without login.
