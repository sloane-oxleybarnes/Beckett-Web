# Beckett beta exit feedback form

Use this as a short Typeform, Google Form, or email survey after a beta tester has finished their testing period. It is intentionally separate from the in-product feedback button, which is for reporting a specific moment or issue.

## Intro copy

**Subject:** A few questions about your Beckett beta experience

Thanks again for testing Beckett. We are wrapping up this phase of the beta and would love an honest read on what was genuinely useful, what fell short, and what would make Beckett worth returning to. This should take about 5 minutes.

## Questions

1. Overall, how useful was Beckett during the beta?
   - Very useful
   - Somewhat useful
   - Neither useful nor unhelpful
   - Not very useful
   - Not useful at all

2. Which parts did you use? Select all that apply.
   - Chrome extension
   - Gmail support
   - Slack support
   - Dashboard coaching
   - Practice conversations
   - Courses
   - I did not get far enough to use a feature regularly

3. Tell us about one moment Beckett was especially helpful — or could have been helpful but missed the mark.
   - Long answer

4. What felt confusing, unreliable, awkward, or missing?
   - Long answer

5. If Beckett disappeared tomorrow, what (if anything) would you miss?
   - Long answer

6. How likely are you to keep using Beckett if it were available to you?
   - Definitely would
   - Probably would
   - Not sure
   - Probably would not
   - Definitely would not

7. What would need to change for you to use Beckett more often?
   - Long answer

8. Would you be open to a 20-minute follow-up conversation?
   - Yes
   - No
   - If yes: What is the best email address and a few times that work?

9. May we follow up about your answers?
   - Yes
   - No

## Closing copy

Thank you. Specific, candid feedback is incredibly useful at this stage. We will only use your responses to improve Beckett and to follow up if you have said that is okay.
